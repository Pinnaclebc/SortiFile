SortiFile Changelog
===================

[2026-10-27] [v1.0.0] 'Official Release' : 'Initial production release with native 60 FPS WPF desktop UI, background directory observer, local Ollama integration, heuristic fallback engine, first-time setup wizard, and 1-click audit undo.'
[2026-10-27] [v1.1.0] 'Hierarchical Subfolders & Multi-Format Support' : 'Added recursive subfolder context inheritance, high-precision backend scoring with whole-number UI display, native PDF text stream extraction, suffix stemming for lazy 1-3 word contexts, and pinned repository changelog link on the dashboard.'
[2026-10-28] [v1.2.0] 'Wizard Redesign, Folder Management & Multi-Select' : 'Streamlined setup wizard without workspace step, added Add+ folder dual-mode creation with mandatory context and subfolder scanning, shift-click range highlighting with custom liquid glass multi-folder context menu, and sorting history reset with undoable action warnings.'
