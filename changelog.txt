SortiFile Changelog
===================

[2026-10-27] [v1.0.0] 'Official Release' : 'Initial production release with native 60 FPS WPF desktop UI, background directory observer, local Ollama integration, heuristic fallback engine, first-time setup wizard, and 1-click audit undo.'
[2026-10-27] [v1.1.0] 'Hierarchical Subfolders & Multi-Format Support' : 'Added recursive subfolder context inheritance, high-precision backend scoring with whole-number UI display, native PDF text stream extraction, suffix stemming for lazy 1-3 word contexts, and pinned repository changelog link on the dashboard.'
[2026-10-28] [v1.2.0] 'Wizard Redesign, Folder Management & Multi-Select' : 'Streamlined setup wizard without workspace step, added Add+ folder dual-mode creation with mandatory context and subfolder scanning, shift-click range highlighting with custom liquid glass multi-folder context menu, and sorting history reset with undoable action warnings.'
[2026-10-28] [v1.2.1] 'Tree Multi-Select Right-Click, Triple-Dot Order Fix & Destination Cleanup' : 'Fixed multi-selection collapsing on right-click, prevented accidental drag-drop folder reordering when clicking folder options, removed Root Workspace option from new folder destination picker, and excluded auto-generated config.json from git repository.'
[2026-10-28] [v1.3.0] 'Registered Folders Architecture, Duplicate Folder Validation & Tree Reset' : 'Decoupled centralized workspace constraint in favor of independent registered folders, implemented duplicate folder validation check and popup dialog in setup wizard and folders tab, added folder tree reset option in settings with typed confirmation prompt without deleting disk files, removed redundant watch directory reset card from settings, and updated default watch and target directory defaults to Desktop.'
[2026-10-28] [v1.3.1] 'Local Changelog Viewer & Build Output Integration' : 'Updated View changelog history to open local changelog.txt directly in the system text viewer with fallback candidates, added automated build packaging for changelog.txt, and bumped version to v1.3.1.'
